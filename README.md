# VerdeVivo – Plataforma Web de Comida Vegana para Llevar  
*Desarrollo Web Móvil – Proyecto Final*

## Descripción General
VerdeVivo es una aplicación web que permite a los usuarios comprar productos veganos, revisar sus detalles (precio, stock, descripción), añadirlos al carrito de compras, modificar cantidades, eliminarlos y vaciar el carrito.  
El sistema utiliza **Node.js + Express**, **MongoDB**, **HTML/CSS/JS**, y una arquitectura MVC simple optimizada para móviles.

Este proyecto cumple con el objetivo principal del curso:  
> **Desarrollar una aplicación web móvil funcional que integre backend, frontend y persistencia de datos.**

---

## Tecnologías Utilizadas
### Frontend
- HTML5, CSS3 y JavaScript
- Diseño responsivo para dispositivos móviles
- DOM manipulation
- Fetch API para consumir el backend

### Backend
- Node.js + Express.js
- Controladores (MVC simplificado)
- API REST para productos y carrito

### Base de Datos
- MongoDB Atlas / MongoDB local
- Mongoose ODM

### Desarrollo
- Git + GitHub
- Visual Studio Code
- GitHub Desktop
- Nodemon (modo desarrollo)
